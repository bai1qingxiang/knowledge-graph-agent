知识图谱 Agent 项目说明

知识图谱 Agent 是一个用于整理项目知识和追踪事实来源的实验项目。
知识图谱 Agent 使用 DeepSeek 从文档中抽取实体、关系和证据。
知识图谱 Agent 使用 FastAPI 提供 HTTP 接口。
知识图谱 Agent 使用 SQLite 保存实体、关系、证据和待审核事实。

张明负责知识图谱 Agent 项目。
事实抽取模块属于知识图谱 Agent。
事实抽取模块依赖 DeepSeek。
审核模块属于知识图谱 Agent。
审核模块依赖 SQLite。

技术方案由张明决定。
技术方案影响知识图谱 Agent。
技术方案记录在《知识图谱 Agent 设计文档》中。

所有模型抽取的结果必须先进入候选区。
候选事实只有经过人工接受后，才能进入正式知识图谱。
每一条正式关系都需要保留能够支持该关系的原文证据。
